# CLK 2.5.0 Worker Wake, Run Patrol, and Layered Progress Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> `superpowers:executing-plans` inline. The Owner prohibits subagents, delegated
> agents, forks, and new Codex tasks for this release. Steps use checkbox syntax
> for tracking.

**Goal:** Release CLK 2.5.0 with a Worker-only four-level Checker wake ladder, one
mechanical Run patrol, exact subtask/subagent definitions, a Supervisor wait
boundary, and receipt/verdict-derived layered progress.

**Architecture:** Add one control-trace schema/template/validator outside the
mutable Runtime index. Replay an injected-time event stream against frozen
Worker/Checker, patrol, and versioned Required-set bindings. Keep detailed rules in
one native reference and expose only compact contract/SPEC/SKILL/readiness clauses.

**Tech Stack:** Python 3.11+, pytest, JSON Schema draft 2020-12, YAML, Markdown,
GitHub Actions.

```python
VALIDATOR = ROOT / "scripts" / "validate_run_control.py"
TEMPLATE = ROOT / "chain-loop-skill/templates/run-control-trace.yaml"

def load_trace() -> dict:
    return yaml.safe_load(TEMPLATE.read_text(encoding="utf-8"))

def run_trace(path: Path, *, optimized: bool = False):
    command = [sys.executable]
    if optimized:
        command.append("-O")
    command.extend([str(VALIDATOR), str(path)])
    return subprocess.run(command, cwd=ROOT, text=True, capture_output=True)
```
