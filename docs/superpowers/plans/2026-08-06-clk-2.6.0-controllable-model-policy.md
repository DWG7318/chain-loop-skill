# CLK 2.6.0 Controllable Model Policy — Implementation Plan

> Execute in this existing CLK owner task. The Owner explicitly forbids new Codex
> tasks, subagents, remote integration, tags, and releases for this candidate.

**Goal:** Implement the Owner-approved configurable model policy without changing
CLK topology or runtime authority.

**Architecture:** Add a standalone, versioned `MODEL_BINDING_LEDGER` contract with a
fail-closed validator. Existing run-control and role-isolation contracts reference
the ledger but keep their current operational state machines.

**Stack:** JSON Schema 2020-12, YAML templates, Python validator, pytest/unittest.

  isolation negatives;

kernel exposes the new policy. Run focused tests and retain the initial failures.
