# CLK 3.0.0 Reconstruction Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task. Execution stays in the current primary conversation; do not use subagents or create formal CLK project members to build CLK itself.

**Goal:** Replace the CLK 2.6.0 control kernel with one small CLK router and eight focused Skills that orchestrate concurrent SLK construction Chains and one final Fusion SLK Chain.

**Architecture:** The active distribution lives under `skills/`. `skills/chain-loop-skill` is the only CLK entrypoint; eight sibling Skills cover Run planning, fusion contracts, temporary parallel isolation, Supervisor understanding, concurrent launch, Chain D2 closure, Fusion launch, and final closure. CLK routes each Chain through the SLK main Skill and never duplicates Checker/Worker/CELL/model/rework/communication behavior owned by SLK 3.0.0.

**Tech Stack:** Markdown Codex Skills and assets, Python 3.12 repository validators/tests, GitHub Actions on Windows and Ubuntu.
